# builders/ — build-as-code (source of truth for everything that isn't a script)

Every map, prop, character, Frame and Titan is generated by Luau builders that run in Studio through the MCP. Read `docs/07_building_with_parts.md` before building anything.

## Local ↔ Studio

Builders are mirrored as ModuleScripts under `ServerStorage.DevTools`. DevTools stays in the place (ServerStorage isn't replicated) and is **never** required by game code.

| Local | Studio |
|---|---|
| `lib/Palette.lua` | `DevTools.Palette` |
| `lib/BuildKit/` (`init.lua` + `Core`, `Structure`, `Detail`, `Fx`, `Gameplay`) | `DevTools.BuildKit` (ModuleScript with 5 child modules) |
| `lib/Props/` (`init.lua` + `Furniture`, `Display`, `Industrial`) | `DevTools.Props` (ModuleScript with child modules; returns a function of BuildKit) |
| `maps/central_command/<Area>.lua` | `DevTools.Builders.CentralCommand.<Area>` |
| `maps/hangar/<Area>.lua` | `DevTools.Builders.Hangar.<Area>` |
| `maps/outpost07/<Area>.lua` | `DevTools.Builders.Outpost07.<Area>` |
| `maps/backdrops/<Area>.lua` | `DevTools.Builders.Backdrops.<Area>` |
| `maps/memory_set.lua` | `DevTools.Builders.MemorySet` |
| `characters/<Name>.lua`, `rigs/<Name>.lua` | `DevTools.Builders.Characters.<Name>`, `DevTools.Builders.Rigs.<Name>` |
| `checks/<Name>` | `DevTools.Checks.<Name>` |

A folder that contains `init.lua` becomes one ModuleScript; the folder's other files become its child modules (same rule as `src/`).

## Running things

Always **clone before require**, so an edited module is never served from `require`'s cache:

```lua
local DT = game:GetService("ServerStorage").DevTools
local BK = require(DT.BuildKit:Clone())     -- BK.Palette is the palette
local builder = require(DT.Builders.CentralCommand.OpsHall:Clone())
return builder.Build({ BK = BK, P = BK.Palette, pass = "blockout" })
```

Self-tests for BuildKit (re-run them after any change to `lib/`):

```lua
local DT = game:GetService("ServerStorage").DevTools
local BK = require(DT.BuildKit:Clone())
local Check = require(DT.Checks.BuildKitCheck:Clone())
return game:GetService("HttpService"):JSONEncode(Check.Full(BK))   -- or Check.Smoke(BK)
```

## Rules for every builder

- **Idempotent:** find the target folder with `BK.folder(parent, name, true)`, which clears it, then rebuild. Never touch anything outside the target.
- **Deterministic:** randomness only through `BK.rng(seed)` with one fixed seed per builder.
- **Passes:** `opts.pass` = `blockout` | `structure` | `dressed`; a higher pass includes the lower ones. Gameplay objects (triggers, prompts, pads, spawns, nav nodes, cam points, barriers) are built in every pass.
- **Return stats:** `return BK.report(target, startClock)` → `{ parts, lights, shadowLights, emitters, guis, ms, warnings }`. Compare them with the budgets in `docs/07` §5.
- **Colors:** only `BK.Palette` keys (`docs/06_art_direction.md` §3). Cyan is reserved for Lattice resonance.
- **Coordinates:** straight from the map docs. Walls are given by their centerlines; the ground floor top is Y 0; North is −Z.
- Keep each builder file under ~800 lines; split big areas.
- Add any new prop to the catalog in `docs/07` §6 before building it, and any new BuildKit function to `docs/07` §3.
